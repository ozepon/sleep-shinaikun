01

配布済みアプリを使う

まず試したい人向け。自分でビルドする準備は不要です。

  1. GitHubの配布ページのAssetsから「sleep-shinaikun-mac.zip」をダウンロード。
  2. ZIPをダブルクリックして展開し、「スリープしない君.app」をアプリケーションフォルダへ移します。旧版は設定画面の「終了」で終了してから入れ替えます。
  3. アプリを開きます。「完了」「ゴミ箱に入れる」だけの警告が出た場合は「完了」を押します。
  4.  →「システム設定」→「プライバシーとセキュリティ」→ 下へスクロールして「セキュリティ」を表示。
  5. スリープしない君がブロックされた説明の「このまま開く」を押し、認証後に「開く」を選びます。未公証アプリを信頼する例外設定です。内容を理解して実行してください。
  6. 画面いちばん上のメニューバーのMacくんをクリックすると設定が開きます。Dockに常駐するアプリではありません。

02

ソースを読んで、自分でビルド

中身を確認してから使いたい人向け。

  1. GitHubのソースでSources、build.sh、SECURITY.mdを確認します。main.swiftはUIと管理者コマンド、BatteryNotifier.swiftは残量監視、NotificationSecurity.swiftは通信と入力制限、PhoneSetup.swiftはQR登録です。
  2. 以下のコマンドでXcode Command Line Toolsを入れます。インストール済みなら不要です。
xcode-select --install

準備できたら、ターミナルでソースを取得してビルドします。

git clone https://github.com/ozepon/sleep-shinaikun.git
cd sleep-shinaikun
git checkout v1.0.6
./build.sh

生成したアプリを開きます。

open "build/スリープしない君.app"

設定読み取りと、外部送信を行わない判定テスト：

"build/スリープしない君.app/Contents/MacOS/LidAwake" --check
"build/スリープしない君.app/Contents/MacOS/LidAwake" --self-test

build.shは現在のMacのCPU向けにコンパイルし、アイコン同梱・アドホック署名を行います。自分でビルドしてもApple公証済みにはなりません。Intel Macは未検証です。コマンドを実行する前にソースを確認してください。

起動しただけでは電源設定は変わりません。通常はスリープ防止の変更に管理者認証が必要です。任意の限定許可を設定すると切替の認証を省略できます。iPhone通知は別途登録します。iPhoneの詳しい登録手順へ ↓

削除時は先にスリープ防止をオフにして終了し、アプリをゴミ箱へ移します。復旧方法と詳しい内部処理はREADMEにあります。

HOW TO USE

操作は、小さなスイッチひとつ。

01

アプリを開く

アプリを開くと、メニューバーに月のアイコンが現れます。起動するだけでは電源設定を変更しません。

02

スリープ防止をオン

アイコンを押してスイッチをオンに。macOSの管理者認証を許可すると、太陽と「ON」の表示に変わります。

03

終わったら、オフに

同じスイッチで戻せます。終了するときも、オフにして終了するかを選べます。オフへの変更にも認証が必要です。

通知の表示イメージ

HELLO, IPHONE

ふたを閉じても、
電池は気にかけて。

Macの残量が10%を切ったら、iPhoneへ。
通知をオンにすると、その場にQRが表示されます。

  1. Macでこのサイトからアプリをダウンロードし、ZIPを展開します。
  2. 「スリープしない君.app」をダブルクリックします。現在は未公証の検証版のため、macOSに起動を制限される場合があります。
  3. Mac画面いちばん上のメニューバー（時計などがある場所）で、月／太陽のアイコンをクリックします。
  4. 開いた設定画面の「iPhoneに低残量を通知」をオンにします。「スリープ防止」とは別のスイッチです。
  5. 通知をオンにすると、同じ設定画面にQRが自動で表示されます。ボタンを押す必要はありません。初回の「通知停止中」は正常です。
  6. iPhoneのカメラでQRを読み、リンクをSafariまたはChromeで開きます。この紹介サイトではなく、ntfy.shの通知受信ページが開きます。
  7. iPhoneのブラウザの共有ボタンから「ホーム画面に追加」→「追加」を選びます。
  8. iPhoneのホーム画面に戻り、追加された「ntfy」アイコンをタップします。通知の許可を求められたら「許可」を選びます。ページに通知を有効にする操作があれば実行してください。
  9. Macのトピックが購読一覧にあることを確認します。なければ「Subscribe」で、MacのQR画面に表示されたトピックを登録します。
  10. Macのアプリで「テスト通知」を押し、iPhoneに通知が表示されることを確認します。
  11. 届いたらMacの「iPhoneで届いたことを確認した（7日間有効にする）」を押します。届かない場合は押さず、iPhoneの通知設定・集中モード・接続を確認します。

iOS 16.4以降・両端のインターネット接続が必要です。QRの読み取りだけでは登録は完了しません。購読が表示されない場合はトピックを追加してください。通知は受信確認から7日間有効です。下の「7日間」の説明も確認してください。

ntfy公式の設定手順 ↗

NOTIFICATION CHECK

通知は受信確認から7日間有効です。

「ntfyを開く」とは、iPhoneのホーム画面に追加したntfyアイコンをタップすることです。Macアプリや紹介サイトを開くことではありません。ntfyのWeb通知は受信ページを1週間以上開かないとサービス側で休止され、再び開くと再開します。公式の説明 ↗

1.0.2では、受信確認から7日でMac側の自動通知を停止します。メニューバーに「⚠︎」、設定画面にオレンジ色の「通知停止中・受信確認が必要です」を表示します。初回も同じ表示です。スリープ防止の設定は変更しません。

  1. iPhoneのホーム画面からntfyを開く。
  2. Macアプリで「テスト通知」を押す。
  3. iPhoneで届いたことを確認する。
  4. Macで「iPhoneで届いたことを確認した」を押す。再び7日間有効になります。

MacはiPhoneの通知許可や実際の不達を検知できません。「⚠︎」は受信確認の期限切れを示します。期限内でも通知許可や購読を取り消すと届きません。通知を受け取るだけ、Macアプリを開くだけでは期限は延びません。

OPTIONAL · v1.0.6

毎回のパスワードを省略する、限定設定。

設定画面の「切替の認証を省略する…」から、初回だけ管理者認証して、スリープのオン・オフ2コマンドだけを許可できます。有料の開発者登録や常駐rootヘルパーは使いません。初期状態は無効です。

同じMacユーザーの他のアプリも、この2操作が可能になります。アプリだけに限定した許可ではありません。任意の管理者コマンドや他のpmset引数はこの規則で許可しませんが、悪意ある同一ユーザーのプロセスによるスリープ切替のリスクは残ります。

  1. Macくん → スリープ防止カードの「切替の認証を省略する…」を押す。
  2. 許可する範囲を確認し、「認証して有効にする」を選んでMacで認証。
  3. 以後の切替は、その2コマンドだけ認証なしで実行。
  4. 解除時は先にスリープ防止をオフにし、「認証省略を解除…」から再認証。アプリを削除する前に必ず解除してください。

専用のsudoersファイルに記録し、メインのsudoersは変更しません。設定前後に構文検証を行います。31項目の非破壊検証を実施しましたが、実際の設定追加・解除と認証なし切替は開発環境では未検証です。詳しい検証と残るリスク ↗

UNDER THE HOOD

何をしているかも、シンプルに。

macOSの電源設定を切り替える

管理者認証を通して、macOS標準のpmsetを実行します。5秒ごとに実際の設定を読み直し、画面に反映。パスワードは保存しません。

ONpmset -a disablesleep 1OFFpmset -a disablesleep 0

disablesleepはAppleの公開ソースに存在しますが、一般向けマニュアルに記載されない設定です。将来のmacOSでの動作は保証できません。

バッテリーを読み、必要なときだけ通知

30秒ごとに内蔵バッテリーを確認。バッテリー駆動中に10%未満なら、ntfy.shへHTTPSで送信します。一度送信すると、15%以上に回復するまで重複を抑えます。

Mac 残量9%→ntfy.sh 通知を配信→iPhone 通知を表示

通信失敗時は5〜60分間隔で再試行。サーバー受け付けとiPhoneへの到達は別です。Macアプリの終了中・スリープ中は監視できません。

PLEASE REMEMBER

使う前に、知っておいてほしいこと。

オンの間は、システム全体のスリープを止めます。

ふたを閉じた場合に限らず、電源アダプタ・バッテリーの両方でスリープを無効にします。通気のよい場所で使い、バッグに収納する前には必ずオフにしてください。

通知のQRとトピックは、共有しないでください。

トピックを知る人は受信・送信できます。QRはiPhone1台に限定するペアリングではありません。通知内容と残量は外部サービスntfyへ送信されます。端末名や管理者パスワードは送信しません。

アプリの強制終了では、設定が残る場合があります。

再びアプリを開いてオフにしてください。ターミナルから sudo pmset -a disablesleep 0 でも戻せます。管理者認証が必要です。

現在は、公開配布に向けた検証版です。

アドホック署名のみで、Developer ID署名・Appleの公証は未実施です。他のMacでは起動が制限される場合があります。不正入力・転送防止・改ざん検知の限定的な検証も実施しましたが、ふたを閉じた実機動作とiPhoneでの受信は未確認です。
