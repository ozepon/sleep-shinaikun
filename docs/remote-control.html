iPhoneから、スリープ防止をオフに。

招待制・50組までの先行検証版です。Macのv1.1.0-beta.1で利用できます。iPhone実機のPush到達・遠隔オフの最終確認は未実施です。

iPhoneの専用アプリを開く ↗ / Macの先行検証版をダウンロード ↗

最初の登録

  1. 本人用の接続JSONファイルを運営から受け取ります。一般の新規登録はありません。ファイルは他人へ共有しないでください。
  2. Macの「専用アプリ接続」で「接続ファイルを読み込む」を押し、受け取ったJSONを選びます。
  3. iPhoneで上の専用アプリを開き、共有からホーム画面に追加します。追加したアイコンから開きます。
  4. iPhoneアプリ内の「MacのQRを読み取る」でMacのQRを読み、「通知を許可して登録」を押します。QRは5分有効。期限切れはMacで「登録コードを発行」をもう一度押します。
  5. Macで「専用通知とiPhoneからのオフ操作」をオンにし、テスト通知を確認します。
  6. 遠隔オフには、Macの「切替の認証を省略する」を一度設定してください。管理者権限をスリープ切替の2操作だけに限定する既存の仕組みです。

使うときの流れ

  1. Macのバッテリーが10%未満になるとiPhoneへ通知。
  2. 通知から専用アプリを開き、「スリープ防止をオフにする」を選ぶ。
  3. Macが約60秒ごとに指示を確認。オフにしてから、実際の設定を読み直す。
  4. オフを確認したMacが結果を報告し、iPhoneへ完了通知。

何も選ばなければ変更しません。Macが受信していない指示は2分で失効します。受信したあと結果が届かない場合は「結果不明」とし、成功扱いにしません。オフ直後のスリープで結果送信が止まる場合は、復帰後に再試行します。

登録と権限

招待されたMacとiPhoneを50組まで登録できます。iPhoneで専用サイトをホーム画面に追加し、そのアイコンから開いてMacの登録QRを読み取ります。QRは5分有効・1回限りです。Apple Developer Programの加入は不要です。遠隔オフにはMac側でスリープ切替の限定許可を設定する必要があります。

攻撃を想定した確認

ローカルのテスト用DBと通知送信の代替処理で検証しています。第三者のサイトやAppleの通知サーバーへの攻撃は行っていません。

  • 偽造トークン、別サイトのOrigin、MacとiPhoneの権限取り違えを拒否。
  • 登録コードの再利用、期限切れ、他のMacによる指示取得を拒否。
  • 二重操作・未実行の成功報告を拒否。
  • 内部ネットワーク宛てなど、不正なPush宛先と巨大なリクエストを拒否。
  • 登録50組、通知1組10回/日・全体500回/日、同時送信2件の制限。

実際のローカルWorker・D1でも、同時クリック10件の統合、暗号化通知の復号、二重送信の拒否、同時登録60件の50組上限を確認しました。API・暗号化テスト結果 / Worker・D1統合テスト結果。テスト通過は脆弱性がないことの保証ではありません。本番Push・実機の開閉・遠隔オフの最終確認は未実施です。無料枠が大量アクセスで尽きるとAPIが停止する場合があります。
